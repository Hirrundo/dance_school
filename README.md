О проекте

TEMPO — веб-приложение для танцевальной школы, предназначенное для организации учебного процесса, управления занятиями, группами, расписанием и бронированием танцевальных залов.

Сайт объединяет учеников, хореографов и администрацию в единой системе. Каждая категория пользователей имеет собственный личный кабинет с доступом к необходимым функциям.

Цель проекта

Разработать веб-приложение для автоматизации работы танцевальной школы, упрощения взаимодействия между учениками, хореографами и администрацией, а также централизованного управления учебным процессом.

Целевая аудитория

Ученики — просмотр расписания, доступ к своим танцевальным группам и видео занятий.

Хореографы — просмотр закреплённых занятий, расписания, бронирование залов и расчёт заработной платы.

Администраторы — управление пользователями, занятиями, группами, заявками и бронированиями.

Основные возможности

Для учеников

Личный кабинет.

Просмотр занятий и расписания.

Просмотр информации о своих группах.

Доступ к видео занятий для участников соответствующих групп.

Для хореографов

Личный кабинет с информацией о закреплённых занятиях.

Просмотр расписания по дням недели.

Отображение ближайшего занятия.

Бронирование танцевальных залов.

Просмотр статусов бронирований.

Калькулятор заработной платы на основе почасовой ставки и количества отработанных часов.

Для администратора

Просмотр статистики школы.

Управление учётными записями пользователей.

Управление занятиями, танцевальными направлениями, стоимостью и хореографами.

Управление группами учеников и расписанием.

Просмотр и обработка заявок на пробные занятия.

Просмотр и обработка бронирований залов.

Управление информацией о студии.

Запуск проекта

Установить Python.

Открыть терминал в каталоге проекта.

Создать виртуальное окружение:

python -m venv venv 

Активировать виртуальное окружение в Windows:

venv\Scripts\activate 

Установить зависимости проекта. Если в корне есть файл requirements.txt, выполнить:

pip install -r requirements.txt 

Применить миграции:

python manage.py migrate 

Запустить сервер разработки:

python manage.py runserver 

Открыть в браузере адрес:

http://127.0.0.1:8000/

Для загрузки демонстрационных данных в чистую базу можно использовать команду:

python manage.py loaddata demo_data.json 

Перед загрузкой необходимо убедиться, что структура базы данных соответствует данным в файле.
